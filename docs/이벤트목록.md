# 이벤트 목록

모든 이벤트는 `<모듈>.<동작>` 형식입니다.
Go 이벤트 버스에서 발행된 이벤트는 Wails 이벤트 `kkomi:event` 로 화면에 그대로 전달됩니다.

공통 형식:
```json
{ "topic": "settings.changed", "source": "settings", "payload": { ... }, "at": "2026-10-23T09:00:00+09:00" }
```

## 구현된 이벤트

| 이벤트 | 발행 모듈 | payload | 구독 모듈 |
|---|---|---|---|
| `system.ping` | system | `{ message }` | (화면) 시스템 정보 |
| `settings.changed` | settings | `{ key, value }` | (화면) settings – 테마/글자 크기 적용 |

## 예정된 이벤트

| 이벤트 | 발행 모듈 | 구독 모듈 |
|---|---|---|
| `eventtype.created/updated/deleted/reordered` | eventtype | myevent, sent, stats |
| `myevent.created/updated/deleted` | myevent | dashboard, schedule, stats |
| `received.created/updated/deleted` | myevent | matching, person, dashboard, stats, auditlog |
| `sent.created/updated/deleted` | sent | matching, person, dashboard, schedule, stats, auditlog |
| `person.merged/updated` | person | matching, myevent, sent |
| `customfield.changed` | customfield | myevent, sent |
| `member.changed`, `mode.changed` | member | 전체 목록 화면 |
| `trash.restored/purged` | trash | 관련 화면 전체 |
| `backup.done/failed`, `import.done` | backup, excel | 알림(Toast) |
| `app.locked/unlocked` | security | 전체 화면 |
